# 🌐 TechNews.sys | Blog de Tecnología e IA

Un blog moderno, ultrarrápido y responsivo construido para publicar editoriales y noticias sobre tecnología, inteligencia artificial y el futuro del desarrollo.

Sitio en vivo: [Aquí irá tu link de Vercel]

## 🚀 Tecnologías Utilizadas

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Estilos:** [Tailwind CSS](https://tailwindcss.com/)
- **Despliegue:** [Vercel](https://vercel.com) (CI/CD Automático)
- **Tipografía:** Fira Code (Mono) & Inter (Sans)

## 📂 Estructura del Proyecto

El proyecto utiliza el sistema de enrutamiento basado en carpetas de Next.js (`App Router`):

```text
app/
 ├── layout.jsx            # Estilos globales, fondo oscuro y metaetiquetas
 ├── page.jsx              # Hub Central (Inicio) con la grilla de artículos
 └── bill-gates-ia/
      └── page.jsx         # Artículo de ejemplo: "La Era de la IA"
